# Zhivex AI SDK 0.12.1 Release Plan

`0.12.1` is a compatibility and production-readiness patch for direct Anthropic Claude Opus 5 support. The package remains Beta and does not widen the stable public surface.

## Included Work

- Catalog and direct `create_anthropic()` guidance now include the fixed model ID `claude-opus-5`.
- Opus 5 uses adaptive thinking by default. Portable effort maps to Anthropic `output_config.effort`; `ReasoningConfig(effort="none")` disables thinking, with the documented `high` ceiling.
- Manual thinking budgets and non-default sampling parameters fail before dispatch.
- Adaptive thinking permits named and required tool choice.
- Non-streaming and SSE tool loops preserve interleaved thinking, redacted-thinking blocks, and signatures in their original order.
- Mid-conversation system sections preserve consecutive system messages and validate their surrounding user or server-tool-result messages.
- Assistant prefill and server-side Web Fetch fail before dispatch for Opus 5, including token counting.
- Refusal details and context-window termination stay observable; collected streaming refusal text is discarded.
- Fast mode automatically sends the required Anthropic beta header.
- The installed-wheel live smoke omits incompatible Anthropic temperature settings and uses a realistic agent output budget.
- The existing Postgres run store and durable agent guarantees remain unchanged.

## Scope Boundaries

- Opus 5 support applies to the first-party Anthropic Messages integration exposed by `create_anthropic()`.
- The existing Bedrock Converse adapter does not claim Opus 5 support.
- Web Fetch and Priority Tier are not claimed for Opus 5.
- Server-side fallback remains a provider-native beta escape hatch rather than a stable portable contract.

## Release Evidence

Before publishing, run:

```bash
make check
make release-check
make release-evidence
```

When Anthropic credentials and model access are configured, validate the exact installed wheel:

```bash
ZHIVEX_SMOKE_USE_INSTALLED=1 \
ZHIVEX_SMOKE_PROVIDERS=anthropic \
ZHIVEX_SMOKE_ANTHROPIC_MODEL=claude-opus-5 \
ZHIVEX_SMOKE_AGENTS=1 \
ZHIVEX_SMOKE_STRICT=1 \
make smoke
```

Do not treat a skipped provider as a successful live validation.
