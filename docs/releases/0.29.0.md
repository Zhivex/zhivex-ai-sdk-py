## Changes and compatibility

`zhivex_ai.experimental` adds `openai_computer_tool`, `ComputerApproval`,
`ComputerScreenshot`, `run_computer_use`, and `ComputerRunResult` without expanding
or removing Stable root exports. OpenAI Responses GA `computer` / `actions[]`
uses the existing generation, streaming and Agent runtime with an application-owned
async authorizer and executor. The SDK provides no browser, OS driver or VM.

- Preserve call IDs, ordered batches and complete provider safety checks. Require
  explicit warning-ID acknowledgement, return correlated screenshots with original
  detail, and retain native replay across durable Agent approval continuation.
- Stop unhandled/unsupported calls and denied approvals rather than reporting
  completed work with zero executions. Reject unfinished response or call items,
  interrupted streams, malformed actions and duplicate IDs in retained history.
- Bound callbacks, including those that suppress cancellation. After executor
  entry, failures in execution, screenshots, guardrails, hooks, cancellation or
  result serialization retain an unknown external outcome and its correlation.
  Approval failures before execution do not claim an effect. Never retry unknown
  effects without application reconciliation.
- Require an independent application postcondition through the experimental
  verification wrapper, including text-only model finals. Model completion is
  separate from verified UI task success.

Existing preview declaration helpers retain their signatures/defaults. Applications
that previously relied on an unexecuted native computer call ending as `completed`
now receive a fail-closed error and must register the GA helper or own the native
controller. There is no automatic native computer executor parity for Azure,
Anthropic, Gemini or Vertex. Applications own isolation, coordinate/pixel validation,
receipts and recovery; no exactly-once guarantee is introduced. See the
[computer contract](../COMPUTER_USE.md) and
[offline example](../../examples/agents/computer_use.py).
