# 0.19.0 Release Plan

Version `0.19.0` promotes a deliberately narrow Meta Model API contract into the ten-provider Tier-1 roster while keeping provider-native breadth outside the Stable core. The package remains Beta.

## Scope

- Stable top-level `create_meta()` factory
- Stable portable Standard `muse-spark-1.2` text generation and streaming
- Stable portable JSON Schema structured output
- Stable portable callable tools and complete agent tool loops
- Meta `tool_choice="auto"` behavior as the supported tool-choice contract
- Tier-1 shared contract, provider-specific, documentation, example, smoke-configuration, and installed-artifact coverage

## Stability Boundary

This promotion does not cover Contributor models, `meta_hosted_tool()`, `meta_web_search_tool()`, `meta_tool_search_tool()`, Files, raw Responses/continuation, hosted tools, or multimodal/native extras. Those remain Beta.

The SDK does not claim Meta embeddings, speech output, transcription, grounding, Realtime, image generation, or video generation.

Meta Model API is upstream GA, but upstream service maturity does not automatically promote every SDK surface. The symbol, model, and operation boundaries above define the Stable SDK contract.

## Required Evidence

- public stability manifest and contract tests agree that `create_meta` is Stable
- the Tier-1 roster contains all ten providers and generated support documentation is regenerated from runtime metadata
- shared Tier-1 contracts cover Meta's documented auto-only tool-choice exception
- Meta provider tests cover Standard text, streaming, structured output, callable tools, errors, and retries
- `make check` and `make release-check` pass against the exact clean release candidate
- existing Stable infrastructure, including the Postgres run store, retains installed-artifact and regression coverage
- an isolated install from the built wheel proves the promoted top-level import and portable model construction
- strict authenticated smoke runs Standard `muse-spark-1.2` generation plus the complete agent tool loop from the exact built artifact
- release evidence records the exact provider, model, operation set, built artifact, and source revision

Worktree and locally built wheel smokes performed before the clean release candidate are integration evidence only. They must not be reused as formal `0.19.0` release certification.

Capture the exact candidate record with:

```bash
make release-evidence
```

## Production Boundary

Production routes should pin Standard `muse-spark-1.2`, retain `tool_choice="auto"`, validate tool arguments in application code, and keep Contributor or native surfaces behind an explicit allowlist and privacy-tier policy. Tier-1 identifies contract support; deployment teams still own credentials, region/model availability, retention and data-use review, rate limits, authorization, and release-specific live certification.
