# 0.28.0 — Agent architecture and provider extensions

This Beta release preserves existing Stable imports while separating agent
contracts, execution, persistence and provider-native extensions into internal
modules. It adds opt-in total execution budgets and bounded trace retention,
nonblocking SQLite transactions, and reusable PostgreSQL connection pools.

## Scope and compatibility

See the [changelog](../../CHANGELOG.md), [architecture guide](../ARCHITECTURE.md)
and [model refresh](../MODEL_REFRESH_2026_09_30.md). Current provider model routes,
OpenAI native multi-agent responses, Anthropic 5.5 extensions, Gemini Voices,
Qwen rerank and LiveTranslate keep their documented compatibility tiers. Offline
contracts and historical live reports do not certify every new provider route.

Defaults remain compatible: execution deadlines and trace limits are opt-in,
SQLite construction remains synchronous, and persisted agent class identities
remain readable. Prefer SQLiteAgentRunStore.open() in async applications and close
owned PostgreSQL stores with their async context manager or close(). Borrowed
pools remain caller-owned. Trace limits count events and preserve final text;
they are not a byte limit. See [production guidance](../../PRODUCTION_APIS.md).

## Release gates

Run `make release-check` for repository checks, wheel/sdist installation, optional
extras, security audits and distribution metadata. Run `make release-evidence`
to record candidate metadata and artifact hashes. The Postgres run store and
pooled agent persistence require PostgreSQL-backed checks; skipped database tests
do not satisfy those gates. Installed artifacts also exercise SQLite, execution
budgets, stream cleanup and trace retention independently of the checkout.

Protected OpenAI/Meta canaries retain the prior release requirements under
[0.28.0-smoke-policy.json](0.28.0-smoke-policy.json). Publication requires green
CI on the reviewed commit, an annotated `v0.28.0` tag matching package metadata,
and successful protected smoke/certification workflows before PyPI publication.
Preparation and the pull request do not publish or create a release tag.

Local candidate results and artifact hashes: [release evidence](0.28.0-evidence.md).
