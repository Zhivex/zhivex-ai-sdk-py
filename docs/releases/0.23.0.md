# 0.23.0 Release Plan

Version `0.23.0` adds explicit stream and HTTP resource ownership, shared stream retention, internal persistence modularization, and the September model refresh. The distribution remains Beta.

## Compatibility

The Stable surface adds `HTTPTransport` and `aclose_default_clients`. Existing streams retain full replay by default; finite `stream_buffer_size` is opt-in and reports consumer overrun explicitly. Persistence imports and serialized data remain compatible. DeepSeek vision remains Experimental; catalog entries alone do not establish live availability.

## Validation

Run `make release-evidence` to collect candidate gates and `make release-check` to verify tests, typing, packaging, installed artifacts, dependency audit, and metadata. The Stable Postgres run store and installed workflow smoke must also pass the CI PostgreSQL service gate. Local results from a dirty worktree are integration evidence, not certification of a tagged commit.

The protected publication policy is `0.23.0-smoke-policy.json`. It retains the OpenAI `gpt-5.6-luna` and Beta Meta `muse-spark-1.2-contributor` synthetic canaries. September model probes are additional evidence and do not replace these required operations or certify untested Azure/Vertex deployments.

## Publication later

1. Review and merge the changes; wait for the complete main CI matrix, including PostgreSQL.
2. Verify that PyPI version `0.23.0` and remote tag `v0.23.0` do not already exist.
3. Create the annotated tag on the approved, clean main commit and push it once.
4. The workflow rebuilds and verifies the artifact, runs the protected exact-wheel live policy, then publishes through Trusted Publishing.
5. Verify registry hashes and retain workflow evidence. No publication or tag is performed during local preparation.
