Run from the repository with an isolated Python environment containing the built wheel, `python-dotenv` and `websockets`:

```sh
ZHIVEX_LIVE_WHEEL=/absolute/path/to/zhivex_ai_sdk-0.24.0-py3-none-any.whl \
ZHIVEX_LIVE_EVIDENCE=/absolute/path/to/new-evidence.json \
/path/to/isolated/python -I scripts/run_september_live_certification.py
```

The output path must be new. `ZHIVEX_LIVE_AGENT_SESSION` can resume an explicitly authorized temporary smoke session and deletes it after the probe; never point it at an application session. `ZHIVEX_LIVE_ONLY` accepts comma-separated `provider:model:operation` selectors for focused runs. Each probe has a 150-second outer deadline and concurrency is bounded to three; existing portable smoke helpers may retry once. Native input/resource creation is not automatically replayed. The process exits nonzero if any selected group fails or is blocked. An interrupted report without `finished_at` is incomplete.
