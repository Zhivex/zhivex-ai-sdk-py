# 0.16.0 Release Plan

Version `0.16.0` is the Evals + Protocols release. The package remains Beta and the existing stable top-level contract is additive and unchanged.

## Scope

- deterministic multi-variant agent experiments with custom metrics and baseline-aware CI gates
- A2A v1 Agent Cards plus official REST/JSON-RPC server wiring
- AG-UI lifecycle translation and official event encoding
- constrained OpenAI Responses-compatible create/stream hosting
- general `zhivex` CLI for inspect, run, eval, serve, and playground workflows
- loopback-first local playground backed by the Responses endpoint
- workflow recovery hardening for interrupt metadata, resumed-step idempotency/metadata, and concurrent idempotent starts

## Stability

All new evaluation experiment, protocol hosting, CLI, and playground surfaces are Beta. No existing stable export is removed, renamed, or reclassified.

## Required evidence

- focused offline tests for eval gates, A2A task/artifact mapping, AG-UI ordering, Responses event order, CLI parsing, and workflow regressions
- complete lint, typing, compile, test, coverage, artifact build, and install-from-wheel gates through `make release-check`
- isolated smoke against supported `a2a-sdk` and `ag-ui-protocol` versions
- optional credentialed provider smoke through `make smoke`; lack of credentials must be reported and must not be represented as live validation
- package metadata, changelog, stability/support/versioning docs, examples, and installed-wheel exports aligned at `0.16.0`
- existing Postgres run store and workflow persistence contracts remain green

Capture the executed candidate record with:

```bash
make release-evidence
```

## Production boundary

Protocol adapters do not provide IAM, tenant ownership, durable task storage, DLP, rate limiting, audit policy, or regulated decision logic. The local playground is not a production console. Applications retain those controls and should expose only server-owned agent/model aliases.
