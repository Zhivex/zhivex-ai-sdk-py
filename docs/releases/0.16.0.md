# 0.16.0 Release Plan

Version `0.16.0` absorbs the planned Production Hardening work into the Evals + Protocols release. The package remains Beta and the existing stable top-level contract is additive and unchanged.

## Scope

- repeated, bounded-concurrency agent trials with latency/token/application-cost metrics, redacted trajectories, JSON/JUnit artifacts, and baseline-aware CI gates
- A2A v1 Agent Cards plus official REST/JSON-RPC server wiring
- AG-UI lifecycle translation and official event encoding
- constrained OpenAI Responses-compatible create/stream hosting with strict validation and optional application-owned result/event replay
- general `zhivex` CLI for inspect, run, eval, serve, and playground workflows
- loopback-only local playground backed by the Responses endpoint
- protocol run-option, safe-error, lifecycle-event, request-limit, storage, and official A2A server injection contracts
- workflow recovery hardening plus optional execution leases, heartbeat/fencing, cooperative cancellation, and persisted adapter suspension/cancellation
- root agent/model/tool/handoff telemetry and trace latency fields

## Stability

All new evaluation experiment, protocol hosting, CLI, and playground surfaces are Beta. No existing stable export is removed, renamed, or reclassified.

## Required evidence

- focused offline tests for trial ordering/concurrency/artifacts, A2A task/store/auth/body limits, AG-UI ordering/safe errors, Responses validation/replay, CLI gates/loopback policy, workflow leases/fencing/cancellation, and telemetry regressions
- complete lint, typing, compile, test, coverage, artifact build, and install-from-wheel gates through `make release-check`
- isolated smoke against supported `a2a-sdk` and `ag-ui-protocol` versions
- optional credentialed provider smoke through `make smoke`; lack of credentials must be reported and must not be represented as live validation
- package metadata, changelog, stability/support/versioning docs, examples, and installed-wheel exports aligned at `0.16.0`
- existing Postgres run store and workflow persistence contracts remain green; the new Postgres lease manager must also be exercised against a real release-candidate DSN

Capture the executed candidate record with:

```bash
make release-evidence
```

## Production boundary

Protocol adapters do not provide IAM, tenant ownership, tenant-scoped durable task/event storage, DLP, rate limiting, audit policy, or regulated decision logic. Workflow leases do not make external side effects transactional. The local playground is not a production console and refuses non-loopback binds. Applications retain these controls and should expose only server-owned agent/model aliases.
