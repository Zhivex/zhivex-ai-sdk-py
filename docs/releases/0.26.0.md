# 0.26.0 — Stable realtime and GPT-Live agents

This release promotes normalized realtime/live-agent contracts and the documented
GPT-Live WebSocket subset to Stable. The distribution remains Beta; this is not a
package-wide GA release.

## Included

- Focused `zhivex_ai.live` imports, preserving root and experimental aliases.
- Bounded realtime retention/cleanup, duplicate-tool protection, completion and
  step-budget enforcement, ordered traces and correct durable approval recovery.
- GPT-Live PCM16 audio/context helpers and client delegation to an Agent with a run
  store, single-reader ownership, approval preservation and explicit finalization.
- Correct OpenAI realtime schemas/history and Gemini setup/history behavior.

See [normalized realtime](../agents/live-realtime.md) and [GPT-Live](../agents/gpt-live.md)
for the exact guarantees. WebRTC, SIP, recording/fork APIs, Responses-managed
GPT-Live delegation and automatic reconnect are outside this Stable promotion.

## Compatibility

Install `zhivex-ai-sdk[realtime]` for built-in WebSocket transport. Retention overrun,
missing completion, invalid closed-session sends and competing GPT-Live readers
fail explicitly. GPT-Live context helpers require nonempty content of at most 500
UTF-8 bytes. Backend actions are not undone by voice interruption or disconnection.
No existing Stable import is removed or renamed.

## Evidence and publication

The protected feature evidence for the pre-version-bump candidate is retained in
[the GPT-Live report](2026-09-19-gpt-live-protected.md): GPT-Live 6/6, OpenAI Realtime
20/20. The previously complete Gemini certification is accepted by explicit user
decision; subsequent partial rechecks are retained separately. Those receipts bind
their original wheel hashes and do not certify new 0.26.0 artifact bytes.

The release workflow builds 0.26.0, runs the complete release gates with PostgreSQL,
installs its exact wheel and requires fresh OpenAI/Meta agent-first canaries before
Trusted Publishing to PyPI. The versioned smoke policy is
[0.26.0-smoke-policy.json](0.26.0-smoke-policy.json).

Publication requires an approved main commit, an annotated `v0.26.0` tag matching
package metadata, successful protected release jobs and verification of PyPI
artifact hashes. This document does not itself assert publication.

Run `make release-evidence` to collect candidate metadata and artifact hashes.
The Postgres run store is covered by the PostgreSQL-backed release gates.
