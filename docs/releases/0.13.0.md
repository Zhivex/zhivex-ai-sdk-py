# Zhivex AI SDK 0.13.0 Release Plan

`0.13.0` adds DeepSeek as a stable tier-1 provider while the package remains Beta.

## Included Work

- `create_deepseek()` is part of the stable top-level public surface.
- Current `deepseek-v4-flash` and `deepseek-v4-pro` models support portable text generation, streaming, JSON structured output, callable tools, and reasoning.
- The dedicated Chat Completions adapter preserves `reasoning_content` across tool loops, retains provider-specific usage details, and normalizes retry and error behavior.
- Strict callable tools and assistant prefix completion select DeepSeek's beta route automatically.
- Retired `deepseek-chat` and `deepseek-reasoner` IDs fail before network dispatch.
- Gateway, catalog, generated support metadata, examples, live smoke, and PyPI/TestPyPI release workflows include DeepSeek.
- Vision, files, embeddings, audio, moderation, and hosted tools remain outside the DeepSeek support contract.
- The existing Postgres run store and durable agent guarantees remain unchanged.

## Stability Position

- Stable: `create_deepseek()` and the portable DeepSeek text, streaming, structured-output, tool, and reasoning contract.
- Beta or experimental: raw provider options, strict-tool beta behavior, prefix completion, and provider-data details.
- Unsupported: DeepSeek vision, files, embeddings, audio, moderation, and hosted tools.

## Release Evidence

Before publishing, run:

```bash
make check
make release-check
make release-evidence
```

Verify the release tag against package metadata:

```bash
.venv/bin/python scripts/verify_release_tag.py --tag v0.13.0
```

When DeepSeek credentials are configured, validate the exact installed wheel:

```bash
ZHIVEX_SMOKE_USE_INSTALLED=1 \
ZHIVEX_SMOKE_PROVIDERS=deepseek \
ZHIVEX_SMOKE_DEEPSEEK_MODEL=deepseek-v4-flash \
ZHIVEX_SMOKE_AGENTS=1 \
ZHIVEX_SMOKE_STRICT=1 \
make smoke
```

Do not treat a skipped provider as successful live validation.
