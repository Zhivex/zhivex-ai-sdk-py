# 0.28.2 — Release preparation and smoke recovery

This Beta candidate carries the [0.28.0 feature scope](0.28.0.md) with corrected
release metadata and OpenAI smoke diagnostics. Existing API compatibility and
provider support classifications remain unchanged.

## Failed attempts

- `v0.28.0`: build passed; the OpenAI generation smoke returned unexpected text,
  Meta passed, and PyPI publication was skipped.
- `v0.28.1`: the tag pointed to package version `0.28.0`; tag verification failed
  before build or publication.

Both tags are protected historical refs. This candidate uses a fresh version
instead of moving them. Historical 0.28.0 wheel hashes and live evidence do not
certify a 0.28.2 artifact.

## Corrections

Package metadata, lockfile, README, release notes and both publication workflows
use `0.28.2`. The OpenAI generation smoke has a bounded 128-token output budget
and reports finish reason and text length without logging response content.
Smoke evidence is uploaded even on failure; publication still requires passing
build and protected smoke jobs.

## Release gates

The [0.28.2 smoke policy](0.28.2-smoke-policy.json) preserves the OpenAI and Meta
models, operations, installed-package check and artifact SHA256 requirements.
Run `make release-check` and `make release-evidence` to record candidate checks
and artifact hashes. The Postgres run store and pooled persistence gates must run
with a configured database. Local tests and skipped database checks do not prove protected live
certification or publication.

Integrate the preparation into `main` and verify CI on the merged commit before
creating a tag. Confirm `pyproject.toml` declares `0.28.2`, the lockfile is current,
and `python scripts/verify_release_tag.py --tag v0.28.2` passes. Confirm the remote
tag does not already exist with `git ls-remote --tags origin refs/tags/v0.28.2`.
Then create the annotated tag on that reviewed commit and push it to trigger
Publish PyPI. Do not create a tag from an unmerged preparation branch.

This document records preparation requirements; protected smoke, certification
and PyPI publication remain pending until the exact candidate passes those jobs.
