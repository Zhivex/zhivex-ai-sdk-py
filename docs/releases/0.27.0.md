# 0.27.0 — Vertex integration expansion

This Beta release expands Google Vertex AI / Gemini Enterprise Agent Platform
support with Express/ADC authentication, current Google model routes and native
Cloud services. Existing Stable imports remain compatible. Install
`zhivex-ai-sdk[vertex]` for ADC and `[realtime]` for built-in WebSocket transport.

## Scope

See the [changelog](../../CHANGELOG.md), [Vertex guide](../providers/vertex.md) and
[coverage/limitations](../providers/vertex-readiness-audit.md). Native resources,
partner routes and model-specific extensions remain Beta. Restricted Google
models, partner access failures and incomplete service workflows do not gain
certification from this release. No further provider expansion is part of this cut.

## Release gates

Run `make release-check` for local checks, wheel/sdist installation, optional extras,
security audit and distribution metadata. Run `make release-evidence` to collect
candidate metadata and artifact hashes. The Postgres run store requires the
PostgreSQL-backed CI gates; skipped local database tests do not satisfy them.

The existing protected OpenAI/Meta canaries are preserved under
[0.27.0-smoke-policy.json](0.27.0-smoke-policy.json). The separate Vertex workflow
is manual and its historical reports do not replace protected publication gates.

Before publishing: review and commit the candidate, pass CI on that commit, create
an annotated `v0.27.0` tag matching package metadata and run protected publishing.
No tag, push or publication is implied by this preparation.

Local results and artifact hashes: [release evidence](0.27.0-evidence.md).
