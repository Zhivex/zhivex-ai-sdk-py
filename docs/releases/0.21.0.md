# 0.21.0 Release Plan

Version `0.21.0` makes gateway cost ceilings operationally fail-closed and adds application-owned provider/model pricing. The distribution remains Beta; this is an additive Stable gateway change, not package-wide GA.

## Scope

- provider/model rates through `GatewayConfig.model_costs_per_1k_tokens`
- model override, canonical catalog alias, catalog price, and deprecated provider-wide fallback precedence
- fail-closed routing for unknown, negative, or non-finite prices whenever `max_cost_per_1k_tokens` is configured
- machine-readable `GatewayAttempt.reason` and `on_attempt.reason` values for policy skips
- preserved eligibility for unknown-price routes when no cost ceiling is configured
- compatibility retention and documented deprecation of `provider_costs_per_1k_tokens`

## Compatibility Boundary

- Existing callers without `max_cost_per_1k_tokens` retain their routing behavior.
- Existing provider-wide rates remain accepted as the lowest-precedence compatibility fallback.
- Rates equal to the configured ceiling remain eligible.
- The gateway compares application-owned rates per 1,000 total tokens; it does not fetch prices or calculate invoices.
- Removing the provider-wide fallback requires the normal Stable deprecation workflow.

## Required Evidence

- unit regressions for lower, equal, higher, unknown, negative, and non-finite prices
- adapter non-invocation proof for strict unknown pricing
- provider/model override and catalog alias precedence coverage
- sanitized callback contract coverage without prompts, responses, or credentials
- public stability, versioning, production, observability, README, and changelog alignment
- existing Stable infrastructure, including the Postgres run store, remains green
- `make check` and `make release-check` pass for the candidate
- wheel and sdist metadata report exactly `0.21.0`
- installed-wheel smoke proves `cost_unknown` before any provider request
- the protected release environment runs the exact wheel under `docs/releases/0.21.0-smoke-policy.json`

The OpenAI and Meta canaries retain the reviewed `0.20.0` model/operation scope. Reusing that policy for `0.21.0` does not turn local tests into live certification; only the protected exact-artifact workflow can produce release evidence for this version.

Capture local candidate evidence with:

```bash
make release-evidence
```

Local or dirty-worktree results are integration evidence. Formal release certification exists only after the clean tagged artifact passes the protected workflow and its evidence is retained.

## Production Boundary

Applications own pricing source, currency, effective date, review cadence, authentication, tenant authorization, retention, and business audit policy. The gateway policy prevents an unpriced or over-budget route from dispatching; it does not guarantee a provider invoice or make downstream effects atomic.
