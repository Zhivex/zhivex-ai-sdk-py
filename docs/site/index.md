# Build portable, durable agents in Python

Zhivex AI SDK combines text and structured generation, agents, durable workflows
and provider routing. Start with the portable contract, then add persistence and
application-owned approvals where your workflow needs them.

The package is **Beta**. Individual APIs carry **Stable**, **Beta** or
**Experimental** labels in the [API reference](reference/index.md).
A Stable API does not imply that every provider/model has live certification.

1. [Install and run your first agent](quickstart.md).
2. [Understand foundation APIs](foundation.md).
3. [Add tools and durable state](agents.md).
4. [Compose workflows](workflows.md) or [route through a gateway](gateway.md).
5. [Choose a provider](providers.md) and review [production responsibilities](production.md).

This site's version and wheel identity appear below and on the reference index.
The reference is generated from an isolated installed wheel, not checkout imports.
