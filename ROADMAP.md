# Roadmap

This roadmap communicates direction, not a guarantee of delivery dates.

## Now

- Keep the portable provider contract aligned across Python and TypeScript.
- Expand credentialed release evidence for Tier-1 providers and agent tool loops.
- Improve examples for durable state, approvals, observability, and gateway routing.

## Next

- Graduate stable surfaces toward a 1.0 release under the documented GA gates.
- Broaden packaged skill validation and safe document workflows.
- Add more production reference architectures for API and worker deployments.

## Later

- Extend multimodal and realtime portability where provider semantics converge.
- Improve cross-SDK compatibility fixtures and conformance reporting.
- Publish deeper performance and cost guidance from reproducible benchmarks.

Please use [GitHub Discussions](https://github.com/Zhivex/zhivex-ai-sdk/discussions) for design proposals and [issues](https://github.com/Zhivex/zhivex-ai-sdk-py/issues) for actionable defects.
